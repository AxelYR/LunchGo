Proyecto web para una pagina basado en hacer el pedido online a una cafeteria, pagar y solo ir a recoger cuando este este listo, evitando espera y agilizando las transacciones.
La pestaña del carrito en la navbar no se actualiza pero el boton 'ir al pago' lleva a la pagina con el carrito real.

Al abrir necesario ejecutar y dejar correr en diferentes consolas de comandos:

npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch

node index.js
